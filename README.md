# 周礼体 (dsh-zhouliti)

> 用四书五经说话，引不到就留白。

一个 [DeepSeek Harness](https://github.com/deepseek-ai) 插件。它把 **14 部经典、8077 条、54.7 万字**的原文收在本地，
让模型在需要「文一点」的时候——**先查原文，再说话**；查不到时说"手边没有出处"，而不是编一句像样的古文。

```
我曾听说，如今读书的人，书是新的，字是新的，人却旧了。
孔子晚年喜《易》，读得书绳断了三次——《史记·孔子世家》「讀《易》，韋編三絕」。
他说的不是用功，是那部书被他翻旧了。
按：把「韦编三绝」当成努力的奖状，是把读旧当成了熬苦。与其添一本新书，不如把手里这本读旧。
你还是好好想想吧。
```

---

## 为什么需要它

让模型「用文言文写点东西」，它几乎总能写得像。问题不在像不像，而在**那句子是不是真存在过**。
「古人云」「据史料记载」后面接的，多半是模型临场造的——写得越像，越难发现。

这个插件把这件事翻过来：**先把可引用的话收在本地，引用必须来自这里**。
- 查到 → 直接给《书名·篇·章句》和原文；
- 查不到 → 明确返回 `found: false`，并告诉模型「必须留白」。

判断"引到了没有"这件事，交给代码而不是模型的自律。

## 四条底线

| # | 底线 | 机制 |
|---|------|------|
| ① | **本地有据优先** | 所有引用先过 `zhouliti_lookup`，语料内置在包里，不走网络 |
| ② | **无据必须留白** | 检索返回 `found:false` + `emptyReason`，规则明令禁止补写 |
| ③ | **引用必带章句号** | 每条命中自带 `citation`，如 `礼记·中庸·13` |
| ④ | **默认不对外发布** | 产出是草稿；插件只在本地记账，不外传任何内容 |

## 装

在 DeepSeek Harness 的图形界面里：**插件 → 安装插件 → 填入包名或本地路径**。

```bash
# 从 npm（发布后）
dsh-zhouliti

# 或从 GitHub
github:<owner>/dsh-zhouliti

# 或直接用本目录（开发时）
/absolute/path/to/dsh-zhouliti
```

装好后到「设置 → 周礼体」能看到本地收了哪些书、引用了多少条。
改完代码要**先卸载再安装**，热更新不会重载宿主端模块。

## 用

插件注册五个工具，模型会在合适的时候自己调用；你也可以直接点名：

| 工具 | 干什么 |
|---|---|
| `zhouliti_lookup` | 查原文。给原句、给出处（`孟子·告子上`）、或给概念（`久坐`）都行 |
| `zhouliti_allusion` | 查典故：原句、故事、可对应的现代处境、**最常见的误用** |
| `zhouliti_compose` | 给主题，返回三段式槽位与可用材料（**不代写正文**） |
| `zhouliti_check` | 对草稿做机械自查：三段式、出处、伪引、长度 |
| `zhouliti_status` | 本地收了什么、这一轮引用了几条 |

简繁两边都认：输入「关关雎鸠」能查到「關關雎鳩」。

## 它不做的

- **不替你判断该不该说**。四条底线里「默认不对外发布」是提醒，不是审查。
- **不假装能判断一切**。`zhouliti_check` 里「删掉引文，剩下的道理还站得住吗」这一问，代码判不了，会如实说"判不了"。
- **不改写原文**。语料只做清洗（去页眉、去校注标记），不改字。

## 开发

```bash
npm test            # 26 个用例：语料完整性、简繁检索、不许凑、体例自查、引用账落盘
npm run build:corpus   # 从原始抓取物重建 data/corpus/
```

```
index.mjs          宿主端：五个工具 + 系统提示注入 + 本地记账
lib/retrieval.mjs  检索：简繁折叠（406 组）、二元组倒排、最长公共子串打分
lib/style.mjs      体例：三段式、禁忌表、自查清单、素材挑选
lib/hostdeps.mjs   宿主依赖的动态加载（不许裸 import @deepseek-ai/*）
client.js          前端：设置页 + 工具卡片（不是 ESM，是自注册脚本）
data/corpus/       14 部书，一部一个 JSON
data/allusions.jsonl  80 条典故
```
